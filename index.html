1. 네이버 지도 Client ID

발급: console.ncloud.com → AI·NAVER API → Application 등록 (Maps 상품 중 Web Dynamic Map, Geocoding 선택) → Client ID(=Key ID) 복사.
Application 설정의 "Web 서비스 URL"에는 포트 번호 없이 호스트만 등록하세요 (예: Live Server면 http://127.0.0.1, 배포 시엔 https://your-domain.com).
키는 브라우저에만 저장되며 서버로 전송되지 않습니다.
